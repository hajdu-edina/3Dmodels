# 3D geosite models – Bakony–Balaton UNESCO Global Geopark

Interactive 3D models of twelve geosites of the Bakony–Balaton UNESCO Global Geopark (Hungary), created with UAV photogrammetry and published via Sketchfab, with an overview map (Leaflet, OpenStreetMap).

Static website, published with GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root).

Authors: Edina Pál-Hajdú, Márton Pál, András Jung – Institute of Cartography and Geoinformatics and Geodiversity & Geoheritage Research Group, ELTE Eötvös Loránd University, Budapest.

Third-party components: LeadMark landing page template (DevCRUD), Bootstrap, jQuery, Isotope, Themify Icons, Leaflet. Map data © OpenStreetMap contributors.
